# Contributing

Build with CMake and run both CTest suites before proposing reader or plotting changes. Add small synthetic FITS/packet fixtures for format changes; keep mission data and generated build files out of the repository.

For a bug report, include app version, macOS/chip type, format/HDU/column names, expected behavior, actual behavior, and a minimal shareable reproduction. Remove private paths and identifiers from logs or screenshots before attaching them. Never upload observation data unless you have permission to redistribute it.

Preserve source units, exact table identifiers, explicit scan limits, and conservative provenance checks. Contributions to project code use the MIT license; dependencies retain their own licenses.

## Attribution

See [AUTHORS.md](AUTHORS.md) for the founding collaboration and equal contributor credit. Preserve accurate commit authorship and add a `Co-authored-by` trailer when work is collaborative. Do not invent historical authorship or contribution dates.
