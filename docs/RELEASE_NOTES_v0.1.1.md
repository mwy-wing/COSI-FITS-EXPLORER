# COSI Explorer v0.1.1 — local preview

- Hover over points for full-precision plotted X/Y, original source row, and stored time. Inspect histogram bins and overlay values.
- Export plot figures to PNG or searchable vector PDF, with labels, units, applied filters, source paths, visible range, and normalization.
- Restore the last file/HDU, plot settings, viewport, window frame, and panel layout.
- Separate Viewer notes from the original FITS header.
- Include the new app logo and native Dock icon.

Apple Silicon, macOS 15+. This local preview is ad-hoc signed and is not Apple-notarized. Public v0.1.0 release assets and tags are unchanged.

Core tests and the public synthetic-data native regression cover filtered point provenance, hover dispatch, linear/logarithmic overlays, figure output, and a second launch with saved workspace settings. No observation data is bundled.
