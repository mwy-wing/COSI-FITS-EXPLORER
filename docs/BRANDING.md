# COSI Explorer logo

![COSI Explorer icon](../resources/COSIExplorer.png)

The logo uses an abstract photon track, two interaction nodes, and broken circular arcs. Its navy, cyan, periwinkle, and violet palette follows the original README branding. This is an independent app identity, not the official COSI mission or NASA logo. It is a decorative mark, not a physical diagram.

- `resources/COSIExplorer.png`: generated 1254 × 1254 RGBA PNG, with transparency outside the tile.
- `resources/COSIExplorer.icns`: native macOS icon with standard and Retina sizes from 16 through 1024 pixels.
- CMake copies the ICNS into the macOS app's Resources folder; Info.plist selects it as the bundle icon. The published v0.1.0 downloads are unchanged.

Created with the built-in imagegen tool. The master PNG is preserved unchanged. macOS sips resized packaging derivatives; iconutil assembled the ICNS.

## Generation prompt

Use case: logo-brand. Asset type: production macOS desktop application icon for COSI Explorer, an independent scientific FITS and gamma-ray event data viewer. Create ONE finished original icon, square 1024 by 1024 canvas, no text or letters anywhere. Transparent canvas outside a single beautifully proportioned rounded square dark midnight navy tile; leave a balanced margin around the tile for use as a macOS Dock icon. Central emblem: an elegantly simplified Compton photon/event track, a bold angular continuous path with two clear circular interaction nodes, and a rising outgoing ray. Use a subtle broken circular arc behind the track to suggest exploration and a soft abstract letter C through negative space, without literal typography. Strong iconic silhouette recognizable at 32 pixels, thick clean strokes, very few elements, balanced composition. Palette matches an existing scientific app brand: deep navy #101d3b tile, cyan #6ee7f9 first track/node transitioning to periwinkle #91a2ff and soft violet #c4a0ff last ray/node. Crisp vector-like geometric construction with restrained premium native macOS polish, very subtle tile gradient and edge light, mostly flat emblem. Keep track/nodes inside generous internal safe margins, no clutter, no small stars, no chart grid, no plot axes, no miniature interface, no satellite or telescope illustration, no magnifying glass, no 3D perspective, no mockup, no extra objects, no watermark. This is a new independent app logo, not the official COSI mission or NASA logo. Output the single icon only with actual alpha transparency outside the tile.
