# README visuals

`overview.png` and `demo.gif` show the actual native COSI Explorer interface using generated synthetic FITS events. The animation cycles through Time, original Row number, and Histogram views, with 2.5 seconds per view. Frames were captured from the app's own native view and encoded as a GIF. No UI elements or plots were drawn over the captures.

The media contain no observation files or personal home-directory paths. The matching synthetic dataset and its generator are in `examples/`. The visuals show implemented features.

`banner.svg` is an original vector banner with an abstract photon-track emblem and decorative spectrum. It does not use the official COSI mission logo or any third-party mascot.
