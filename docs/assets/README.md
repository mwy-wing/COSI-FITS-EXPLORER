# README preview

`overview.png` is rendered by the actual native COSI Explorer interface using generated synthetic FITS events. It contains no observation files or personal home-directory paths. The temporary demo dataset is not included in the repository. The image is a product screenshot, not an illustration of unimplemented features.

`banner.svg` is an original vector banner with an abstract photon-track emblem and decorative spectrum. It does not use the official COSI mission logo or any third-party mascot.
