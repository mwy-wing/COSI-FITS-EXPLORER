# Changelog

## [0.1.1](https://github.com/mwy-wing/COSI-FITS-EXPLORER/releases/tag/v0.1.1) — 2026-10-27

- Point inspection and linked original-row selection.
- Pan, rectangle zoom, and Back/Reset navigation.
- All rows / Plotted rows tables with original row numbers and jumps.
- Column summaries and full-precision copying; explicit scan limits and partial-data labels.
- PNG/PDF figure export, CSV, and workspace restoration.
- Flat vector icon, synthetic demo, and automated macOS/Linux builds.

## [0.1.0](https://github.com/mwy-wing/COSI-FITS-EXPLORER/releases/tag/v0.1.0) — first public release

- Read-only FITS and supported COSI packet viewing.
- Time/row plots, histograms, spectrum comparison, and CSV export.
- Paged tables, full row fields, headers, images, hit geometry, and conservative event tracing.
- C++ reader/CLI, fixture tests, MIT licensing, and Mac DMG/ZIP downloads.
